## Install

```bash
npm i @sereneinserenade/tiptap-extensions
```

`@tiptap/core` and `@tiptap/pm` version 3 are peer dependencies, so your editor setup already has them.

## Use

Import each extension from its own path, or from the package root. Both give the same bundle, because the package is marked side effect free.

```ts
import { Editor } from '@tiptap/core'
import StarterKit from '@tiptap/starter-kit'
import { CommentExtension } from '@sereneinserenade/tiptap-extensions/comment'

new Editor({
  element: document.querySelector('#editor')!,
  extensions: [StarterKit, CommentExtension],
})
```

The extensions use no UI framework. They work the same with React, Vue, Svelte or plain JavaScript. The demos on this site use `@tiptap/react`.
