## Usage

```ts
import { CommentExtension } from '@sereneinserenade/tiptap-extensions/comment'

CommentExtension.configure({
  onCommentActivated: (commentId) => setActiveThread(commentId),
})
```

## Commands

| Command | What it does |
| --- | --- |
| `setComment(commentId)` | Marks the selection with a comment id. |
| `unsetComment(commentId)` | Removes every mark with that id. |

## Styling

Commented text renders as `span[data-comment-id]`.
