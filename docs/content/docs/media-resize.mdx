## Usage

```ts
import { ResizableMedia } from '@sereneinserenade/tiptap-extensions/media-resize'

editor.commands.setMedia({ 'media-type': 'img', src: '/photo.jpg', width: 320 })
```

Typing `![alt](url)` also inserts an image.

## Styling

Style `.media-node-view`, `.media-node-view__toolbar` and `.media-node-view__handle`. Alignment and float are on the `data-align` and `data-float` attributes.
