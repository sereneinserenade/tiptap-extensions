## Usage

```ts
import { Video } from '@sereneinserenade/tiptap-extensions/video'

editor.commands.setVideo('https://example.com/clip.mp4')
```

## Commands

| Command | What it does |
| --- | --- |
| `setVideo(src)` | Inserts a video. |
| `toggleVideo(src)` | Inserts a video, or turns the selected one back into a paragraph. |
