## Usage

```ts
import { InlineSuggestion } from '@sereneinserenade/tiptap-extensions/inline-suggestion'

InlineSuggestion.configure({
  fetchAutocompletion: async (existingText) => {
    const res = await fetch('/api/complete', { method: 'POST', body: existingText })
    return res.text()
  },
})
```

## Commands

| Command | What it does |
| --- | --- |
| `fetchSuggestion()` | Accepts the shown suggestion, or fetches one for the current node. Tab runs it. |

## Styling

The suggestion is in the `data-inline-suggestion` attribute. Show it with `[data-inline-suggestion]::after { content: attr(data-inline-suggestion) }`.
